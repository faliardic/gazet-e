# Gazette

## Durum: Mobile V2 aktif geliştirme / v1.1 legacy stabil

Bu repository iki ayrı yaşam döngüsünü birlikte taşır:

- **Mobile V2:** aktif ürün geliştirmesi. Kullanıcının tek dokunuşla güncel bir kişisel gazete hazırlattığı, klasik basılı gazete görünümünü mobilde interaktif olarak okuduğu yeni ürün yönü.
- **v1.1 legacy:** mevcut Python tabanlı RSS → HTML/PDF/static-web gazete üreticisi. Q02 architecture audit tamamlanmadan silinmez veya toplu yeniden yazılmaz.

V2 public/commercial marka adı henüz dondurulmamıştır. Repository teknik adı `chatgpt-haber` korunur; v1.1 arayüzlerinde görünen `ChatGPT Gazette` adı V2 commercial brand kararı değildir.

`docs/` klasörü GitHub Pages publication output alanıdır; V2 governance dokümantasyonu `project_docs/` altında tutulur.

## Mobile V2 ürün özeti

V2'nin ana hareketi **`Gazetemi Hazırla`** eylemidir. Sistem güncel haberleri toplar, tekrarları azaltır, önem sırasına koyar, kısa Gazette özetleri ve AI editoryal görseller üretir, ardından sonucu klasik basılı gazete sayfalarına yerleştirir.

İki primary reading mode vardır:

- **Gazete Modu:** tam gazete sayfası, pinch-zoom, pan/scroll, sayfa geçişi ve tıklanabilir haber bölgeleri.
- **Okuma Modu:** telefona uygun article view, AI editoryal görsel, Gazette özeti, kaynak ve `Kaynağa Git` eylemi.

Görünür V2 haber görselleri AI-generated by default olarak tasarlanır. Hassas gerçek olaylarda AI görseli gerçekte çekilmiş kanıt fotoğrafı izlenimi vermemelidir.

## v1.1 hızlı kullanım

Kurulum:

```powershell
python -m pip install -e .
python -m playwright install chromium
```

Yerel örnek veriyle hızlı gazete üretimi:

```powershell
python -m chatgpt_haber.cli build --mode fast --no-live --input-json examples\issue.sample.json --out dist\gazete.pdf
```

Canlı RSS akışlarıyla full kalite üretim:

```powershell
python -m chatgpt_haber.cli build --mode full --out dist\gazete.pdf
```

## Legacy web sitesini güncelleme

GitHub Pages çıktısı `main` dalındaki `docs/` klasöründen yayınlanır.

Offline test yayını:

```powershell
python -m chatgpt_haber.cli publish-pages --no-live --input-json examples\issue.sample.json
```

Canlı site çıktısını güncelleme:

```powershell
python -m chatgpt_haber.cli publish-pages
```

Bu komut `docs/index.html`, `docs/gazete.pdf`, `docs/issue.json` ve `docs/archive/` tarih arşivini günceller.

## v1.1 mimari baseline

Ana akış:

```text
RSS veya issue JSON -> normalize -> teknoloji sayfası garantisi -> editoryal filtre -> görsel zenginleştirme -> doğrulama -> HTML -> PDF
```

Önemli modüller:

- `chatgpt_haber/cli.py`: komut satırı girişleri.
- `chatgpt_haber/pages_publish.py`: GitHub Pages statik site yayını.
- `chatgpt_haber/render.py`: HTML ve PDF render.
- `chatgpt_haber/builder.py`: RSS tabanlı sayı üretimi.
- `chatgpt_haber/technology_page.py`: üçüncü sayfa teknoloji garantisi.
- `services/news_quality_filters.py`: final güvenlik ve kalite filtreleri.

## v1.1 bilinen sınırlar

- Canlı üretim RSS kaynaklarının erişilebilirliğine bağlıdır.
- PDF üretimi için Playwright Chromium gerekir.
- Windows EXE klasörü tek dosya değildir; bağımlılık klasörüyle birlikte dağıtılır.
- Statik site kullanıcı hesabı, backend veya veritabanı içermez.

## Yaşam döngüsü politikası

v1.1 legacy davranışı kritik hata, bozuk RSS kaynağı, güvenlik, bağımlılık/işletim sistemi uyumluluğu ve GitHub Pages yayın hataları için korunur.

Yeni mobil V2 feature'ları `AGENTS.md` ve `ROADMAP.md` üzerinden yürütülür. v1.1 maintenance politikası V2 geliştirmesini engellemez; V2 de audit/Issue authority olmadan legacy sistemi sessizce kırmaz.
